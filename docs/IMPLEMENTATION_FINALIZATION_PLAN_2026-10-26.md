# 구현 마무리 작업 계획

기존 문서는 수정하지 않는다. 사용자 확정 난이도는 `BALANCE_TARGET_2026-10-26.md`를 따른다. 다른 세션의 에셋 문서/산출물 연결은 이번 범위에서 보류한다.

| 항목 | 영향도 |
| --- | --- |
| 요구사항 | 혼합·방향 대응 편성으로 안정적 진행. 첫 시도 통계와 재시도 가능한 실제 사용을 구분 |
| 기획 근거 | 구현 설계 §10, 사용자 결정 보충 D-01~12, 최신 보통 난이도 답변 |
| 수정 범위 | 후보 v10 활성 설정, 시뮬레이션 분석 도구, UI 안내/복원, 추가 증거 문서 |
| 간접 영향 | 저장 configVersion=candidate-v10, 비용/보상/확장, 100웨이브, 정적 스키마, locale |
| 미결정 | 핵심 규칙 답변 완료. 실제 재미와 최종 아트는 이번 검사로 판정하지 않음 |
| 완료 기준 | 아래 정적/계산 근거와 I-01~23 개별 대응 기록. 검사하지 않은 런타임은 미검증 유지 |

- [ ] 후보 v10: 8개 정책 × 1,000 시드, 같은 seed 위치/강화 비교 완료. `balance:simulate --policies all --paired`.
- [ ] 별도 보류 시드 100000..100999: mixed/recon/wrong 재측정. 기준 달성 여부와 Wilson 구간 기록.
- [ ] 보병/장갑/항공에 대한 12병과의 실제 전투 기여와 상위 연구 변화를 통제된 도메인 전투로 측정. 같은 칸 수와 지출 차이를 명시하여 무료 상위 병과를 효율 우위로 오인하지 않음.
- [ ] 경제/구간별 생존과 잔액, 편성 다양성/실패 정책, 틱 상한/무효/회계 검사 분석.
- [ ] 저장 복원 후 HUD, 준비 타이머, 중복 진행 잠금, 트리 다음 목표/완료 알림, 임시 병과 식별 개선. 정적 검사와 소스 검토만 적용.
- [ ] 전체 `check:all`, 정적 번들 `build`, 원본 보존 범위 및 공유 Git 상태 확인.
- [ ] 신규 최종 상태 문서에 구현 근거/미검증/남은 작업을 남김. 기존 문서의 과거 후보·미결정 기록은 새 문서에서 정정.

원래 작업 브랜치는 `feat/implementation-design`이며 main에 기준 커밋이 없는 초기 저장소였다. 공유 폴더의 HEAD는 다른 세션에서 `feat/ww-asset-sessions`로 바뀌었다. 이 작업에서는 이를 되돌리거나 다른 세션의 파일을 스테이징하지 않는다. 별도 리뷰 에이전트는 사용량 제한으로 실행되지 못했으므로 독립 리뷰 합격을 주장하지 않는다.
