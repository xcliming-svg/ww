# 난이도 목표 추가 확정

사용자 답변: **보통 — 적절한 혼합·대응 편성은 안정적으로 진행**.

기존 문서/리포트는 변경하지 않는다. 후보 7까지의 측정은 어려운 최초 후보를 조사한 기록이다. 사용자 목표에 맞춰 이후 후보를 재측정한다.

내부 캘리브레이션 지표(게임 규칙이 아님): 같은 seed의 첫 시도 캠페인에서 정찰 대응 정책 완주율 80% 이상, 혼합 정책 60% 이상을 우선 목표로 사용한다. 의도적으로 잘못된 편성은 5% 이하, 비정상 종료/음수 재화/회계 불일치는 0건, 위치 교환과 강화 제거의 결과 차이가 관측되어야 한다. 이 백분율은 사용자가 직접 선택한 숫자가 아니라 '안정적으로 진행'을 측정하기 위한 구현 측정 기준이다.

실제 사용자는 같은 웨이브를 다시 편성할 수 있다. 자동 정책의 첫 시도 완주율은 실제 사람의 난이도/재미를 대신 증명하지 않는다. 브라우저/플레이 검증은 계속 미실시한다.
