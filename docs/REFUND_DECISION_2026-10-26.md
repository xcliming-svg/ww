# 환불 결정과 구현 계약

최신 사용자 답변: 반복 환불로 돈이 없어 이후 진행이 막힐 수 있으면 100% 환불, 기다리면 군수물자가 들어오는 구조라면 일부 패널티를 고려한다. 현재 게임은 성공 보상으로만 물자를 지급하고 시간 수입은 없다. 따라서 이 조건에 따라 **준비 단계의 영구 투자도 실제 지출액 100% 환불**을 적용한다. 기존 원본 문서의 연구·강화 환불 불가 규칙을 이 추가 결정이 대체한다. 새 수입 타이머는 만들지 않는다.

사용자는 이후 세션 시작 시 개발 진행률을 먼저 알려 달라고 요청했다. 시작 보고에는 에셋 제외 구현 추정과 정적 검증/출시 준비를 구분한다.

| 항목 | 영향도 |
| --- | --- |
| 요구사항 | 연구·강화에 과투자했어도 준비에서 투자금을 회수하여 재편성. 반복 구매/환불로 이득·손실 없음 |
| 기획 근거 | 2026-10-26 환불 조건 답변, 앞선 하위 노드 동시 처리 제안. 전투 중 변경 금지와 배치 취소 100% 유지 |
| 수정 범위 | RefundService, EconomyService, GameState/명령/저장 계약, DOM 미리보기, locale, save schema/migration, 시뮬 정책 |
| 간접 영향 | DAG/시설 의존, 종류별 강화, 배치 취소, 재시도 스냅샷, 저장 버전, 경제 회계, 최종 측정 재실행 |
| 미결정 | 환불률 추가 질문 없음. 신규 타이머·수입·실패 보상 없음 |
| 완료 기준 | 비용 원장-보유 상태 정적 계약, 원자적 미리보기/실행, 필수 노드 보호, 준비 잠금, 신규 스키마/마이그레이션 및 순수 경제/전투 시뮬 |

- [ ] 구매마다 실제 지출액 원장 기록. 기본 지급 HQ/병영/소총 연구는 제거·현금화 불가.
- [ ] 연구/구매 건물 환불 시 **실제 선행·생산시설 의존**을 잃는 하위 연구·유닛 강화만 함께 제거. 그림상 가까운 노드나 형제 분기는 보존.
- [ ] 영향받는 배치 유닛은 구매비 100%로 취소. 전투를 치르고 소멸한 부대 구매비는 환불 대상이 아님.
- [ ] 강화만 되돌리기 지원. 연구 자체와 배치 유닛은 유지하고 선택 종류의 강화 원장만 환불.
- [ ] 실행 전 제거 연구·강화·배치 목록 및 총 환불액 확인. 중복 클릭/오래된 미리보기 거부, 처리 전부 성공 또는 전부 실패.
- [ ] 저장 v2에 원장 포함, v1은 체크섬/스키마/콘텐츠 일치 확인 후 당시 고정 비용으로 복원. 알 수 없는 가격의 저장을 현재 가격으로 추정하지 않음.
- [ ] 다수 seed 캠페인에 구매/환불 왕복을 포함하여 회계 및 결과 안정성을 측정. 브라우저/일반 런타임 테스트는 수행하지 않음.

## 참고 검토

- [Mechabellum Research Center](https://mbwiki.dreamhaven.com/buildings/research-center/): Field Recovery가 지정 부대 투자 물자를 전액 반환. 영구 연구 환불과 동일한 기능이라는 뜻은 아니다.
- [BTD6 공식 제공사 도움말](https://help.netflix.com/en/node/718990757024356): 영구 지식 트리는 정액 재설정 비용으로 포인트 전체를 반환하며 개별 노드 환불은 제공하지 않는다.
- [Grim Dawn 공식 가이드](https://www.grimdawn.com/guide/gameplay/service-npcs/): 비용을 내고 포인트를 되돌릴 수 있으며 의존하는 패시브를 제거해야 선행 액티브를 제거할 수 있다.

100% 환불은 이 게임의 무시간수입·같은 웨이브 재시도·보통 난이도를 고려한 사용자 조건 적용이다. 다른 게임의 환불률을 그대로 복사한 규칙이 아니다. 패배 반복으로 새 물자를 받거나 연구를 유지하면서 환불받는 경우를 허용하지 않는다.
